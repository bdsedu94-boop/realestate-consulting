# 추천물건 캡처 도우미 (크롬 확장프로그램)

컨설팅 사이트의 추천물건 편집창에서 **[🤖 탱크옥션 자동 캡처]** 버튼을 누르면 다음 순서로 진행됩니다.

1. 이 크롬에 로그인된 탱크옥션에서 사건번호를 검색해 물건 상세 페이지를 엽니다.
2. **경매정보 · 임차인 현황 · 등기** 세 영역을 각각 캡처합니다.
3. 캡처한 이미지를 리포트에 첨부합니다.

## 설치 (담당자 PC마다 1회)

1. 이 폴더(`tank-capture-extension`)를 PC에 복사합니다.
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택합니다.
5. 컨설팅 사이트를 새로고침합니다.

※ 같은 크롬에서 탱크옥션에 로그인되어 있어야 합니다.

## 동작 방식

- **이미 열린 페이지 우선:** 해당 사건의 상세 페이지가 이미 열려 있으면 그 탭을 바로 캡처합니다(검색 생략).
- **검색:** 열린 페이지가 없으면 새 창에서 검색 → 결과 클릭 → 상세 페이지 순서로 진행하고, 캡처가 끝나면 창을 닫습니다.
- **이름 가림:** 소유자·채무자·임차인·권리자 중 사람 이름으로 보이는 값을 캡처 전에 `홍○○`처럼 가립니다. 회사·은행 이름은 그대로 둡니다. 캡처가 끝나면 화면은 원래대로 돌아옵니다.
- **인근 낙찰가율:** 상세 페이지 아래 '매각사례' 표의 평균매각가율을 읽어 `83.4% ~ 87.2% (최근 12개월 17건 · 경기 고양시 일산서구 주엽동 아파트)` 형태의 글자로 입찰 전략 칸을 채웁니다. 이 표는 캡처하지 않습니다.
- **읽어오는 값:** 매각기일, 법원, 감정가, 최저가, 유찰 횟수, 한 줄 요약을 읽어 사이트의 **빈 칸만** 채웁니다.
- **실행 범위:** 버튼을 누를 때 1건씩만 실행하며, 단계 사이에 사람이 보는 속도로 대기합니다.
- **창 상단 안내:** 캡처하는 동안 "디버깅 중" 안내줄이 잠깐 보이는 것은 정상입니다. 화면 밖 영역까지 한 장으로 캡처하려고 크롬 캡처 기능을 쓰기 때문입니다. 끝날 때까지 안내줄을 닫지 마세요.
- **긴 영역:** 등기처럼 아주 긴 영역은 나눠 찍은 뒤 한 장으로 이어 붙입니다.

## 잘 안 될 때

- **검색이 안 될 때:** 확장프로그램 아이콘 → 설정에서 **검색 주소**를 지정하면 가장 안정적입니다. 탱크옥션에서 사건번호로 한 번 검색한 뒤 주소창 주소에 사건번호가 들어 있다면, 그 부분을 `{year}`, `{num}`, `{case}`로 바꿔 붙여넣으세요.
  - 예: `https://www.tankauction.com/ca/caList.php?...&year={year}&no={num}`
- **영역을 못 찾을 때:** 물건 상세 페이지를 열어 두고 설정 화면의 **[열린 탱크옥션 탭 진단]**을 누르세요. 결과 내용을 개발 담당자에게 전달하면 됩니다.
- **섹션 이름이 다를 때:** 섹션 제목이 다르면(예: "집합건물등기") 설정의 섹션 제목 칸에 추가하세요.
- **"캡처 권한" 오류가 날 때:** 탱크옥션 탭에서 개발자도구(F12)가 열려 있으면 닫고 다시 시도하세요.
- **캡처 중 연결이 끊길 때:** 캡처하는 동안 창 위쪽 "디버깅 중" 안내줄의 [취소]나 ✕를 누르면 캡처가 중단됩니다. 탭이 닫히거나 다른 페이지로 넘어가도 중단됩니다. 그 밖의 이유로 연결이 끊기면 같은 페이지일 때만 1번 자동으로 다시 연결해 이어서 캡처합니다. 다른 확장프로그램이 끼어드는 것 같으면 잠시 끄고 다시 시도하세요.

## 사이트 주소가 바뀌면

`manifest.json`의 `host_permissions`와 `content_scripts.matches`에 새 주소를 추가한 뒤, `chrome://extensions`에서 새로고침(↻)하세요.
